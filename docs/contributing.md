# Contributing to Superphenix

Thank you for thinking about contributing to Superphenix !

We've been developing Superphenix as a small team for more than two years now.
We're still working on how to onboard new contributors to the project.

For now, you can consult our [contributing guidelines](https://github.com/super-phenix/superphenix/blob/main/CONTRIBUTING.md).

CI runs on every pull request. The site must build with `zensical build --strict`, and every commit must carry a [Developer Certificate of Origin](https://developercertificate.org/) sign-off that matches the commit author. `git commit -s` adds it.
